# Great House Social Overhaul

Мод для классического Morrowind с MWSE-Lua. Первый срез Core создаёт
версионированный профиль игрока в сохранении.
GHSO начисляет влияние в Доме Телванни за подтверждённую сдачу
[поддерживаемых заданий](docs/API_NOTES.md#начисление-влияния).
Действующий член Дома с этим влиянием может
[получать припасы](docs/TEST_PLAN.md#поставщики-телванни) у поставщиков Дома
раз в семь игровых дней.
Восстановление магии доступно при влиянии от 1, левитация — от 3.
Один выбор темы `GHSO Claim Supplies` выдаёт все доступные позиции.
Влияние, места выдачи и сроки можно посмотреть в `Mod Config → GHSO`.

Текущий срез разработки сосредоточен на Доме Телванни. Пилот
региональной репутации отложен. Возврат кольца Фарготу сохраняет
свои ванильные последствия.

## Запуск для разработки

1. Из корня проекта запустите `python tools/build/package_test.py`.
   Установите `release/GHSO-test.zip` в тестовый профиль. При ручной
   установке распакуйте архив в каталог Morrowind. В Mod Organizer
   укажите вложенный каталог `Data Files` как корень данных.
2. Запустите Morrowind через этот профиль. На старте найдите в `MWSE.log`
   строку `[GHSO] Core initialized`.
3. Начните новую игру или загрузите тестовое сохранение. Проверьте,
   что журнал сообщает о создании или загрузке профиля.

Архив содержит тестовый ESP. Для прогона Core оставьте его отключённым.
Для совместной проверки ванильных данных включите ESP и откройте
[тестовый диалог Фаргота](docs/TEST_PLAN.md#диалог-фаргота).
